Step 3 of 5 · Browser permission

Turn on Chrome's User Scripts permission

SeenDisJob detects duplicates by injecting its detector through Chrome's userScripts API. Chrome requires this toggle to be flipped by hand — no extension can enable it for you.

Required This page rechecks automatically when you come back to this tab.

Step 4 of 5 · Pin extension

Pin SeenDisJob to your toolbar

Optional Detection already works without this — pinning just keeps the popup and dashboard one click away.

1

Click the puzzle-piece icon in Chrome's toolbar.

2

Find SeenDisJob in the list.

3

Click the pin icon next to it.

Why Chrome asks for this

SeenDisJob runs its detector in Chrome's USER_SCRIPT world, which is the execution context Chrome built for on-demand userscript-style injection. Chrome gates that API behind a manual toggle so no extension can start injecting scripts without a deliberate, human action.

On Chrome 138 and later this is a per-extension Allow User Scripts switch, in addition to Developer mode. On earlier versions, Developer mode alone is enough.

What this does not change

The permission lets SeenDisJob read job pages you visit. It does not create an account, open a network connection, or sync anything. The detector that runs in that world cannot reach storage directly — everything it finds is handed to the extension and kept on this device.
